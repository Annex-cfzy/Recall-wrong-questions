## 4. 详细测试用例

### TC-M2-001 · 拍照录入全流程（AC-1.1）
- **类型**：功能 / 端到端
- **优先级**：P0
- **接口**：`POST /api/errors/upload`（multipart）→ `POST /api/errors/import`
- **步骤**：
  1. 录入页选择「拍照」Tab，拖拽或 Ctrl+V 粘贴含 3 题的图片；
  2. 触发上传，等待 OCR（mock 下 < 1s 返回 3 题）；
  3. OCR 预览页默认 3 题全勾选，可编辑题干；
  4. 选目标错题本 → 点击「导入」
- **预期结果**：
  - `upload` 返回 `ocr_text` + `questions`（3 项，`selected=true`）；
  - `import` 返回 `imported` 列表，每项含 `knowledge_points` / `error_cause` / `mastery=0` / `next_review=次日`；
  - 错题集对应错题本数量 +N，列表出现 3 张错题卡
- **性能**：mock 环境端到端 < 3s；真实 OCR 目标 ≤ 10s
- **实际结果**：⬜ / **状态**：⬜

### TC-M2-002 · 不支持的图片格式（AC-1.2）
- **类型**：功能 / 异常
- **优先级**：P0
- **接口**：`POST /api/errors/upload`（文件类型 `image/bmp` 或 `.bmp`）
- **步骤**：上传一张 `.bmp` 图片
- **预期结果**：
  - 响应 `code=3001`，`message="不支持的图片格式，请上传 JPG/PNG/WEBP 格式"`；
  - 前端 `ElMessage` 错误提示，不上传
- **实际结果**：⬜ / **状态**：⬜

### TC-M2-003 · 图片过大（AC-1.3）
- **类型**：功能 / 异常
- **优先级**：P0
- **接口**：`POST /api/errors/upload`（文件 > 10MB，配置 `max_upload_size`）
- **步骤**：上传 15MB 图片
- **预期结果**：
  - 响应 `code=3002`（或等价大小错误码），提示「图片超过 10MB 限制」；
  - 前端在 DropUpload 处拦截并提示
- **实际结果**：⬜ / **状态**：⬜

### TC-M2-004 · OCR 识别失败（AC-1.4）
- **类型**：功能 / 异常
- **优先级**：P1
- **步骤**：上传极度模糊 / 空白图片，OCR 无法解析出题目
- **预期结果**：
  - 提示「未能识别到题目，请重新上传或改用文本录入」；
  - 提供「重新上传」与「切换文本录入」两个入口
- **实际结果**：⬜ / **状态**：⬜

### TC-M2-005 · 未勾选题目导入（AC-1.5）
- **类型**：功能 / 异常
- **优先级**：P1
- **步骤**：OCR 预览后取消全部勾选 → 点击导入
- **预期结果**：
  - 前端禁用「导入」按钮或提示「请至少勾选 1 道题」；
  - 不发导入请求
- **实际结果**：⬜ / **状态**：⬜

### TC-M2-006 · 文本空提交（AC-1.6）
- **类型**：功能 / 异常
- **优先级**：P1
- **接口**：`POST /api/errors/text`（body 中 `question` 为空）
- **步骤**：文本 Tab 直接点击「保存」，题干为空
- **预期结果**：
  - 前端表单校验拦截，提示「请输入题干」；
  - 或接口返回参数校验错误 `code=1001`
- **实际结果**：⬜ / **状态**：⬜

### TC-M2-007 · FTS5 全文搜索（AC-3.1）
- **类型**：接口 / 性能
- **优先级**：P0
- **接口**：`GET /api/errors?search=导数`
- **步骤**：
  1. 预先录入含「导数」关键词的错题；
  2. 调用搜索并记录响应耗时
- **预期结果**：
  - 返回匹配错题；`search` 走 `errors_fts MATCH` 全文索引；
  - 单次搜索耗时 < 300ms（空库 + 百条数据下）；
  - 前端搜索框输入后列表即时过滤，命中关键词高亮
- **实际结果**：⬜ / **状态**：⬜

### TC-M2-008 · 多维筛选（AC-3.2）
- **类型**：接口 / 功能
- **优先级**：P1
- **接口**：`GET /api/errors?subject=数学&mastery_min=0&mastery_max=50&sort=created_at&order=desc`
- **步骤**：组合学科 + 掌握度区间 + 排序筛选
- **预期结果**：
  - 返回结果均满足 `subject=数学` 且 `mastery∈[0,50]`；
  - `sort/order` 生效；分页 `total/page/page_size` 正确
- **实际结果**：⬜ / **状态**：⬜
