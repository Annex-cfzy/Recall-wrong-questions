## 4. 详细测试用例

### TC-M1-001 · 后端启动（AC-M1.1）
- **类型**：功能 / 冒烟
- **优先级**：P0
- **前置条件**：`backend/.env` 存在（或默认配置生效），Python venv 已装核心依赖
- **步骤**：
  1. `cd backend && uvicorn app.main:app --reload --port 8000`
  2. 观察终端日志，等待 `Uvicorn running on http://127.0.0.1:8000`
  3. 访问 `GET http://localhost:8000/api/health`
- **预期结果**：
  - 终端无 Traceback；
  - `/api/health` 返回 `{"code":0,"message":"success","data":{"status":"ok"}}`
  - 首次启动在 `backend/data/` 生成 `recall.db` 并自动建表
- **实际结果**：⬜
- **状态**：⬜

## 5. 接口自动化断言（建议 pytest）

| 用例 | 方法 / 路径 | 断言 |
|---|---|---|
| API-M1-01 | POST /api/notebooks | 201 等价 `code=0`，`data.id>0`，`error_count==0` |
| API-M1-02 | GET /api/notebooks | `items` 为数组，字段齐全 |
| API-M1-03 | PUT /api/notebooks/{id} | 返回 `data.id` 与入参一致 |
| API-M1-04 | DELETE /api/notebooks/{id} | `code=0`，`deleted_errors>=0` |
| API-M1-05 | DELETE /api/notebooks/{id}(不存在) | `code=200`（业务码，资源不存在类） |

---

## 6. 备注

- M1 不引入真实 OCR/LLM；`MOCK_EXTERNAL=true` 下服务返回确定性占位数据，便于离线验证。
- SQLite 使用 WAL 模式 + `foreign_keys=ON`（见 `core/database.py`）。
- 若启动报 `ModuleNotFoundError`，先确认 venv 已安装 `requirements.txt` 核心依赖。
