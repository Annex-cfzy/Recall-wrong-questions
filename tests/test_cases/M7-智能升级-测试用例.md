# M7 智能升级 — 测试用例文档

> 依据用户升级需求，在**不改动 M1–M6 现有功能**的前提下，新增 4 大类升级能力。
> 所有新功能均为「新建文件 + 新路由 + 新页面」，原 错题集 / 录入 / 复习 / AI答疑 / 数据看板 / 导出 逻辑保持不变。
> 后端默认 `MOCK_EXTERNAL=true`，全部升级逻辑基于已有 `errors` / `review_records` 数据聚合，断网无 Key 即可运行。

## 二、AI 能力深化

### AC-M7.1 错题语音讲解
- **给定**：存在至少 1 道错题
- **当** 进入「语音讲解」页并选择该题
- **则** 返回结构化讲解卡（题目 / 知识点 / 错因 / 解析 / 答案 五段）+ 口播稿 `tts_script`
- **且** 点击「朗读」调用浏览器 `speechSynthesis`（zh-CN）真实发声；暂停/停止可用
- **验证**：`GET /api/upgrade/voice-card/{id}` → `code=0`，含 `tts_script` 非空（`test_upgrade_api.py::test_upgrade_endpoints`）
- **边界**：错题不存在 → `code!=0`（HTTP 仍为 200，统一信封）（`test_voice_card_missing_error`）

### AC-M7.2 考前冲刺清单
- **给定**：存在错题数据
- **当** 进入「考前冲刺」页
- **则** 展示「复习重点」（按掌握度升序的最薄弱知识点，含原因与建议）与「模拟组卷」（掌握度最低的 N 道易错题，含参考答案）
- **且** 可调整重点数 / 题量并重算
- **验证**：`GET /api/upgrade/sprint` → `focus_count>=1`、`mock_paper` 长度 ≤ 题量、最弱题进入组卷（`test_insight_service.py::test_build_sprint`）

## 三、数据智能洞察

### AC-M7.3 数据看板升级（深化维度）
- **掌握趋势**：按知识点给出时间维度掌握度折线（取最薄弱的 6 个知识点）
- **错因分布**：按 `error_cause` 统计饼图
- **薄弱学科对比**：按学科展示薄弱度横向柱（掌握度 + 错误率综合评分）
- **验证**：`GET /api/upgrade/insights` → 含 `mastery_trend` / `error_cause_distribution` / `weak_subject_comparison`（`test_upgrade_endpoints`）
- **单测**：`test_error_cause_distribution`、`test_weak_subject_comparison`、`test_knowledge_mastery_trend`

### AC-M7.4 错题去重聚类
- **给定** 两道题干高度相似的错题（如「求 f(x)=x² 的导数」与「求 f(x)=x³ 的导数」）
- **当** 进入「相似错题」页（阈值中=0.5）
- **则** 被聚合为同一相似簇，并列出「反复出错的知识点」
- **验证**：`GET /api/upgrade/clusters` → `repeated_cluster_count>=1`、成员数 ≥2（`test_detect_clusters_groups_similar`、`test_detect_clusters_repeated_knowledge_points`）
- **说明**：仅识别与分组，**不删除/合并任何已有数据**（符合「不修改现有成果」）

### AC-M7.5 薄弱点预警
- **给定** 某知识点掌握度低或错误率高
- **当** 进入「智能洞察」页
- **则** 顶部展示预警卡片（warning / danger 分级），列出掌握度、错误率、是否近期突增及原因
- **验证**：`weak_point_warnings` 含该知识点，`level∈{warning,danger}`（`test_weak_point_warnings`）

## 四、多端与多场景

### AC-M7.6 语音录入
- **当** 进入「语音录入」页并点击「开始口述」
- **则** 通过 `webkitSpeechRecognition` 实时转写为题目文本（Chrome/Edge 桌面版支持；不支持时给出提示且可手动输入）
- **且** 选择错题本后「保存为错题」→ 调用 `POST /api/errors/text` 入库
- **说明**：真实浏览器能力，离线可用

### AC-M7.7 多端云同步（指示）
- TopBar 新增「已同步」状态指示，表达数据由后端统一存储、Web/小程序可互通
- **说明**：当前为单后端服务，数据天然集中；联机小程序为后续形态

### AC-M7.8 移动端适配
- 各升级页均含 `@media (max-width:767px)` 响应式布局；TopBar 导航在移动端图标化并可横滑，搜索框与同步指示按需隐藏
- 原 `AppLayout` / `TopBar` 仅在末尾追加媒体查询规则，未改动既有桌面布局

## 五、角色扩展与系统化
