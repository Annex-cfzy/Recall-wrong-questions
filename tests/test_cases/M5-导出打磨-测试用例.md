# M5 测试用例 — 导出 + 打磨

> 里程碑：M5（导出 + 打磨） · 对应开发规划 §2.5（W5）、§7.1（AC-7.1 / AC-7.2 / AC-M5.1 / AC-M5.2 / AC-M5.3）
> 测试类型：功能验证 + 边界验证 + 响应式验证
> 测试环境：前端 `npm run dev`（Vite 5173），后端 `uvicorn app.main:app --port 8000`（MOCK_EXTERNAL=true）

---

## 0. 测试范围与前置

| 模块 | 文件 | 说明 |
|------|------|------|
| 导出后端 | `backend/app/api/export.py`、`backend/app/services/export_service.py` | PDF（WeasyPrint，缺失降级 HTML）+ Markdown |
| 导出前端 | `frontend/src/components/ExportModal.vue`、`frontend/src/api/export.ts` | 格式选择 + 选项 + 下载 |
| 错误提示 | `frontend/src/constants/errors.ts`、`frontend/src/api/http.ts` | 业务码 + UI 场景集中映射 |
| 空状态 | `frontend/src/components/EmptyState.vue` + 4 个页面引用 | 引导式空态 |
| 响应式 | 各页面 `<style>` 断点 | 1200 / 768 / 375 三档 |
| 错题编辑 | `backend/app/api/errors.py` `PUT /api/errors/{id}` + `frontend/src/components/ErrorEditModal.vue` | T5.8 |

**前置数据**：至少 1 个错题本（含 ≥2 道含答案/解析/错因的错题）、1 个空错题本。

## 4. AC-M5.2 错误提示全覆盖（14 种 → 已覆盖 23 条）

错误提示集中维护于 `frontend/src/constants/errors.ts`，由 `http.ts` 拦截器按业务码自动映射；UI 级场景由组件直接引用 `UI_ERRORS`。

### 4.1 业务错误码（后端抛出，前端自动提示）

| 码 | 场景 | 文案 |
|----|------|------|
| 1001 | 参数校验失败 | 请求参数校验失败，请检查输入 |
| 2001 | 错题本不存在 | 目标错题本不存在，请刷新后重试 |
| 2002 | 错题不存在 | 错题不存在，可能已被删除 |
| 3001 | 图片格式不支持 | 不支持的图片格式，请上传 JPG/PNG/WEBP 格式 |
| 3002 | 图片超限 | 图片超过 10MB 限制，请压缩后重试 |
| 3003 | OCR 无文字 | 未识别到文字内容，请重新拍照或手动输入 |
| 4001 | AI 服务不可用 | AI 服务暂时不可用，请稍后重试 |
| 5001 | 无待复习 | 当前没有需要复习的题目 |
| 5002 | 复习会话过期 | 复习会话已过期，请重新开始复习 |
| 9000 | 系统错误 | 服务器内部错误，请稍后重试 |

### 4.2 UI 级场景（组件直接引用）

| 键 | 场景 | 文案 |
|----|------|------|
| NO_NOTEBOOK_SELECTED | 未选错题本导入 | 请先选择一个错题本 |
| NO_ERROR_SELECTED | 未勾选题目 | 请至少勾选 1 道题再导入 |
| EMPTY_QUESTION | 题干为空 | 请输入题干内容 |
| UNCHARGED_ANSWERS | 复习有未作答 | 有题目尚未作答 |
| NETWORK | 网络中断 | 网络连接中断，请检查网络后重试 |
| EXPORT_EMPTY | 导出空本 | 该错题本还没有错题，暂无可导出的内容 |
| SAVE_FAILED | 保存失败 | 保存失败，请重试 |
| VARIANT_FAILED | 变体题失败 | 变体题生成失败，请点击重试 |
| STREAM_INTERRUPTED | 对话中断 | 回答中断，已保留已输出的内容 |
| DELETE_CONFIRM | 删除二次确认 | 删除后数据将无法恢复，确认继续吗？ |
| UPLOAD_FAILED | 上传失败 | 图片上传失败，请重试或更换图片 |
| CHAT_EMPTY | 对话空发送 | 请输入问题后再发送 |
| NOTEBOOK_NAME_REQUIRED | 笔记本名为空 | 请填写错题本名称 |

> 14 种最小必需场景（格式/大小/OCR/空提交/无勾选/无待复习/未作答/变体失败/导出空/网络/系统/删除确认/上传失败/会话过期）**已全部覆盖**，并额外超出 9 条。
