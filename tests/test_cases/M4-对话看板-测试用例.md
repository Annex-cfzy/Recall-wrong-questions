## 4. 详细测试用例

### TC-M4-001 · SSE 流式首字延迟（AC-1.7 性能）
- **类型**：接口 / 性能
- **优先级**：P0
- **接口**：`POST /api/chat/stream`（SSE）
- **步骤**：建立 SSE 连接，记录从发送请求到收到首个 `{"type":"chunk"}` 的时间
- **预期结果**：
  - 首字延迟 < 2s（mock 环境 < 500ms）；
  - 事件流顺序：`start` → 多个 `chunk` → `done`
- **实际结果**：⬜ / **状态**：⬜

### TC-M4-002 · 流式中断保留 + 重试（AC-1.7）
- **类型**：功能 / 异常
- **优先级**：P0
- **步骤**：
  1. 对话进行中手动断开网络 / 关闭连接；
  2. 观察前端已输出内容；
  3. 点击「重试」
- **预期结果**：
  - 已输出的文字保留在气泡中，不被清空；
  - 显示「重试」按钮；点击后重新建立流式连接并续写
- **实际结果**：⬜ / **状态**：⬜

### TC-M4-003 · 数据看板 5 图渲染（AC-6.1）
- **类型**：功能 / UI
- **优先级**：P0
- **接口**：`GET /api/dashboard/trends?days=30`、`GET /api/dashboard/knowledge-graph`
- **步骤**：打开「看板」页
- **预期结果**：
  - 渲染 5 种图表：录入趋势（折线）、复习趋势（柱+正确率）、掌握度分布（饼）、学科分布（饼）、平均掌握度趋势（折线）；
  - 全部渲染 < 1s（mock 数据）；
  - 鼠标 hover 显示对应数值 tooltip；
  - 顶部 4 张汇总卡（总错题/总复习/平均掌握/正确率）数值正确
- **实际结果**：⬜ / **状态**：⬜

### TC-M4-004 · 知识图谱（AC-6.2）
- **类型**：功能 / UI
- **优先级**：P1
- **接口**：`GET /api/dashboard/knowledge-graph`
- **预期结果**：
  - `nodes` 节点大小正比于 `error_count`、颜色按 `mastery` 映射（低→红 / 中→橙 / 高→绿）；
  - `edges` 表示知识点共现关系；
  - 图谱支持滚轮缩放 + 拖拽节点；
  - 空数据时显示引导空状态
- **实际结果**：⬜ / **状态**：⬜
