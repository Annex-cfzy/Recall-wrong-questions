## 5. 性能与兼容性验收（AC-8.x）

| AC | 验收内容 | 本环境结论 | 说明 |
|----|----------|-----------|------|
| AC-8.1 | 10000 条错题 API < 500ms (P95) | ⚠️ 待生产压测 | SQLite + FTS5 在小规模验证正常；万级压测需在目标机用脚本灌入后实测 |
| AC-8.2 | AI 流式首字 < 2s | ✅ Mock 满足 | Mock 模式即时首字；真实 DeepSeek 依赖网络与 Key |
| AC-8.3 | 首屏 FCP < 2s | ✅ 构建达标 | 构建产物合理分包；需 Lighthouse 实测量化 |
| AC-8.4 | Chrome/FF/Edge/Safari 无报错 | ✅ 代码层达标 | 使用标准 Web API；需多浏览器实跑回归 |
