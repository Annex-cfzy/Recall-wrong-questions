## 4. SM-2 算法单元测试用例（与 PRD 附录 A 一致）

### TC-M3-005 · SM-2 答对（AC-5.1）
- **类型**：单元
- **优先级**：P0
- **前置**：`quality=5`（满分），初始 `repetition=1, interval_days=6, ease_factor=2.5, mastery=35`
- **断言**：
  - `repetition` → 2
  - `interval_days` → `round(6 * 2.5)` = 15
  - `ease_factor` → 上升（> 2.5，按 SM-2 公式 `EF' = EF + (0.1 - (5-q)*(0.08+(5-q)*0.02))`，q=5 时 +0.10 → 2.6）
  - `mastery` 上调（如 35 → 45）
  - `next_review` 顺延 `interval_days` 天
- **实际结果**：⬜ / **状态**：⬜

### TC-M3-006 · SM-2 答错（AC-5.2）
- **类型**：单元
- **优先级**：P0
- **前置**：`quality<=2`（答错），初始 `repetition=1, interval_days=6, ease_factor=2.5, mastery=35`
- **断言**：
  - `repetition` → 0
  - `interval_days` → 1
  - `ease_factor` → 下降（< 2.5）
  - `mastery` 下调（如 35 → 20）
  - `next_review` → 次日
- **实际结果**：⬜ / **状态**：⬜

## 5. 端到端 / 接口测试用例

### TC-M3-001 · 复习正常流程（AC-4.1）
- **类型**：端到端 / 功能
- **优先级**：P0
- **接口**：`GET /api/review/today` → `POST /api/review/start` → `POST /api/review/submit`
- **步骤**：
  1. 准备若干 `next_review<=今天` 的错题；
  2. 阶段1 选范围（学科/错题本/数量）→ 开始；
  3. `start` 返回 `review_id` + `questions`（含 `variant_question`）；
  4. 阶段2 逐题作答并提交；
  5. `submit` 返回批改结果
- **预期结果**：
  - `start` 的 `total` 与所选数量一致；
  - `submit` 返回 `total_score / correct_count / wrong_count / results[]`；
  - 每题含 `is_correct / score / quality / ai_feedback / standard_answer / sm2_updated`；
  - 批改端到端 < 15s（mock 下 < 2s）
- **实际结果**：⬜ / **状态**：⬜

### TC-M3-002 · 无待复习（AC-4.2）
- **类型**：功能 / 异常
- **优先级**：P0
- **接口**：`POST /api/review/start`（库中所有错题 `next_review` 均在未来）
- **预期结果**：
  - 响应 `code=5001`，`message="当前没有需要复习的题目"`；
  - 前端提示「今天没有需要复习的题目」并引导去录入/看板
- **实际结果**：⬜ / **状态**：⬜

### TC-M3-003 · 未作答提交（AC-4.3）
- **类型**：功能 / 异常
- **优先级**：P1
- **步骤**：复习作答阶段跳过 N 道题（答案留空）直接提交
- **预期结果**：
  - 前端提示「有 N 道题未作答」，阻止提交或标记跳过；
  - 若放行跳过，结果中 `skipped_count=N`
- **实际结果**：⬜ / **状态**：⬜

### TC-M3-004 · 变体题生成失败（AC-4.4）
- **类型**：功能 / 异常
- **优先级**：P1
- **步骤**：模拟 `generate_variant` 失败（mock 下可临时抛错）
- **预期结果**：
  - `start` 返回明确错误 + 前端显示「变体题生成失败，请重试」+ 重试按钮；
  - 重试可恢复
- **实际结果**：⬜ / **状态**：⬜
